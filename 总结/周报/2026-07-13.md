## 一、本周工作概述

本周完成了 `XY_DirectAW_DC_Calibration` 实验的采集、离线分析、文档与实验入口整理，并于 2026-07-13 完成首轮完整数据采集。实验目标是在 DirectAW 物理链路下，建立恒定包络电压与 Z 向小信号响应峰位之间的映射，为后续将目标控制频率换算为 DirectAW 波形幅度提供实验标定。

本轮数据表明，响应峰位主要由包络电压的绝对值决定。以 `|V_env| >= 0.25 V` 的 16 个非零电压点拟合得到：

$$
f_{\mathrm{peak}} = (15075.785 \pm 130.908) |V_{\mathrm{env}}|
-(218.475 \pm 165.263)\ \mathrm{Hz},
$$

其中 $R^2=0.99895$，RMSE 为 280.58 Hz。该结果目前可作为初步换算关系，但由于所有电压组的未屏蔽最大响应均落在固定 20 kHz 相干杂散处，仍需通过 Z-RF OFF 背景扣除实验复核后才能作为最终标定。

### 2. 完成 DirectAW 实验链路

DirectAW 由 `dg_comp` CH1/CH2 直接输出 X/Y 正交任意波，不经过 `dg_am -> dg_comp AM EXT` 外部调制链路：

$$
X(t)=V_{\mathrm{env}}\cos(2\pi f_Lt+\phi),
$$

$$
Y(t)=V_{\mathrm{env}}\cos(2\pi f_Lt+\phi+90^\circ).
$$

实现内容包括：

- 固定 DG 任意波输出为 4 Vpp、0 V offset，只通过上传数组改变恒定包络电压。
- 采用 100 Hz 外部触发同步 X/Y 两路，重新上传波形时先停止触发，再共同重新触发两路输出。
- 自动校准 DirectAW 整体相位。本轮从初始误差 `63.079 deg` 收敛到 `0.052 deg`，最终控制相位为 `298.910 deg`。
- 使用 `Demod0 Y -> AuxOut2 -> SignalInput2 DC -> Demod3` 物理回环，使 Demod3 可以直接按 Z 驱动频率读取复响应。
- 每个测量点关闭温控磁场干扰，采集完成后恢复温控；扫描主体使用 `try/finally`，异常时关闭相关输出。
- 输出设置前执行安全限值校验，并将 mapping、safety limits 和时钟源读回结果写入实验配置。

## 三、实验方法

### 1. 扫描设计

实验采用双层逐点扫描：外层改变 DirectAW 恒定包络电压，内层扫描 Z 向弱射频场频率，在每个电压下寻找频率响应峰。

| 参数 | 本轮设置 |
|---|---:|
| DirectAW 包络电压 | -2.00 至 +2.00 V |
| 电压步进 / 点数 | 0.25 V / 17 点 |
| AW 固定输出 | 4 Vpp，0 V offset |
| AW 重复频率 / 点数 | 500 Hz / 10000 点 |
| X/Y 载波频率 | 10 kHz |
| X/Y 正交相位差 | 90 deg |
| X/Y 外触发 | 100 Hz，5 Vpp，2.5 V offset，50% duty |
| Z RF 频率 | 500 Hz 至 35 kHz，步进 500 Hz |
| Z RF 幅度 | 0.01 Vpp |
| 每频点稳定 / 采集时间 | 0.5 s / 1.0 s |
| Pump 调制 | 10 kHz，5% duty，0.18 Vpp |
| 固定主磁场 | 1.03 mA |
| Cell 温度 | 100 degC |

共完成 `17 x 70 = 1190` 个 Z 频率测量点，原始目录包含 1243 个文件，大小约 2.06 GiB。

### 2. 数据采集

采集模式为 `both`，每个频点同时保存：

- Demod0 `sample.y` 的 1 s 时域数据，实际采样率约 115131.58 Sa/s；
- Demod3 的 X/Y/R/theta 采样及复矢量均值；
- 当前频率、包络电压、实际 Demod3 rate、time constant 和输入通道；
- 每个包络电压对应的 DirectAW X/Y 波形快照。

Demod3 以 Z 驱动频率作为参考，time constant 按驱动周期自适应，并以复矢量均值
`sqrt(mean(X)^2 + mean(Y)^2)` 作为硬件响应量。Demod0 时域数据保留用于离线锁相与 FFT 交叉检查。

### 3. 离线分析

离线分析流程如下：

1. 按包络电压分组，读取每组 70 个 Z 扫频点。
2. 从 Demod0 时域数据计算整数周期离线正交锁相幅值和 nearest-bin FFT 幅值。
3. 优先使用 Demod3 硬件复矢量均值作为标定响应；无硬件结果时回退到离线锁相。
4. 在峰值拟合前屏蔽已确认的 19--21 kHz 固定相干杂散，同时保留未屏蔽最大频点和邻近屏蔽带标记。
5. 分别尝试 Bloch 稳态响应模型和单 Lorentzian 模型；优先选择 Bloch 模型，若其残差明显更差则使用 Lorentzian，失败时回退到最大采样点。
6. 分别拟合有符号全局关系、正电压支路、负电压绝对值支路和 `|V_env|` 主模型，并比较正负对称性。

正、负支路斜率仅相差约 0.67%，而有符号全局拟合几乎没有解释力。这与 DirectAW 负包络仅使 X/Y 正交旋转场整体翻转 180 deg 的物理预期一致：响应峰频率主要由 `|V_env|` 决定，符号主要改变相位而非控制强度。

$$
|V_{\mathrm{env}}| \approx
\frac{f_{\mathrm{target}}+218.475}{15075.785}.
$$

该关系只建议用于本轮覆盖的 `|V_env| = 0.25--2.00 V`、约 3.6--30.0 kHz 范围，并应保留电压符号所代表的相位方向。

### 2. 正负电压对称性

- 8 组正负配对点的平均峰位绝对差为 316.7 Hz。
- 最大差异出现在 `|V_env| = 0.75 V`，`f(+V)-f(-V)=1086.1 Hz`。
- 除 0.75 V 外，其余配对差异约为 116--304 Hz。
- `V_env = 0 V` 的拟合中心为 500 Hz，位于扫描下边界，因此未纳入 `|V|` 主模型，不能视为可靠的零电压共振中心。

![正负包络电压的峰位对称性](../../data/XY_DirectAW_DC_Calibration/0713_1119_direct_aw_dc_cal/results/direct_aw_sign_symmetry.png)

*图 3：正、负包络电压的配对峰位及差值。`|V_env| = 0.75 V` 的正负差异显著高于其余配对点，是后续重复测量的重点。*

### 3. 固定杂散与可信度

- 17 个电压组的未屏蔽最大响应均位于 20 kHz，说明该分量不随 Z 驱动频率移动，属于固定相干杂散而非标定峰。
- 当前分析屏蔽 19、19.5、20、20.5 和 21 kHz 五个频点后再拟合真实响应峰。
- `V_env = -1.50、-1.25、+1.25、+1.50 V` 的拟合中心位于屏蔽带邻域，已标记为低可信度。
- 17 个电压点均完成峰值拟合，但“拟合成功”只表示数值模型收敛，不等于杂散影响已经完全消除。

![典型包络电压下的 Z 频率响应](../../data/XY_DirectAW_DC_Calibration/0713_1119_direct_aw_dc_cal/results/direct_aw_frequency_response_examples.png)

## 五、当前结论

1. DirectAW 恒定包络电压与响应峰位在 `|V_env| = 0.25--2.00 V` 范围内呈良好的绝对值线性关系，初步比例系数约为 15.08 kHz/V。
2. 包络电压正负号主要对应旋转场 180 deg 相位翻转，不能使用单一有符号直线描述峰频。
3. 当前正电压支路的一致性最好，RMSE 仅 44.61 Hz；负电压支路及正负对称性仍存在额外偏差。
4. 20 kHz 固定相干杂散是当前结果的主要系统误差。屏蔽法能够得到初步标定，但无法恢复真实峰穿过 19--21 kHz 区间时的信息。

## 六、下一步计划

1. 增加 Z-RF OFF 背景采集，对 Demod3 复数响应 `X+iY` 做逐点 ON-OFF 扣除，再重新拟合峰位。

3. 对 `+/-1.25 V` 和 `+/-1.50 V` 在 17--23 kHz 区间加密扫描，评估真实峰经过固定杂散带时的偏差。

### 3. 第二次标定的数据筛选

第二次虽然将扫频上限扩展到 50 kHz，但 `|V_env| = 3.0 V` 时主响应最大采样点
已经到达 50 kHz 上边界，峰形没有被完整覆盖。根据峰频随 `|V_env|` 连续增大的
物理关系，从 `|V_env| = 3.0 V` 起及更高电压的真实峰只会继续移出当前扫频范围。
因此离线分析自动执行以下筛选：

- 保留 `V_env = +/-0.5、+/-1.0、+/-1.5、+/-2.0、+/-2.5 V`，共 10 点；
- 排除 `V_env = +/-3.0、+/-3.5、+/-4.0 V`，避免把边界或约 40 kHz 的次峰误认为真实峰；
- `V_env = 0 V` 仍因峰位位于 500 Hz 扫频下边界且低于绝对值拟合阈值而排除；
- 19--21 kHz 固定相干杂散继续在拟峰前屏蔽。17 个电压组的未屏蔽最大值仍全部位于 20 kHz，说明该系统误差尚未消失。

第二次绝对值主模型的实际有效电压范围为 `|V_env| = 0.5--2.5 V`，对应拟合峰位
约为 7.8--39.9 kHz。高电压原始拟合点仍保留在结果文件和图中，但以灰色叉号
标记，且不参与标定系数计算。

把 3.88% 的差异直接解释为标定漂移或重复性误差。

当前应保留两套带条件的标定结果：第一次在更密的 0.25 V 电压步进下具有更小的
拟合不确定度；第二次验证了 8 Vpp 设置下可扩展到 `|V_env| = 2.5 V`，但也明确表明
50 kHz 扫频上限不足以可靠标定 `|V_env| >= 3.0 V`。若要得到可合并的最终系数，
下一轮应固定同一 AW 满量程、采集模式、触发策略和校相流程，并把 Z RF 扫频上限
扩展到预计峰位之外，同时加入 Z-RF OFF 复数背景扣除。
