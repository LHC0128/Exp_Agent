# DG4000 与示波器 CH3 电压采样接线说明

## 现象

将示波器 CH3 的 BNC 插入或拔出后，锁相放大器的 `R` 信号出现明显变化。这通常不是因为示波器的输入电阻太小，而是因为普通台式示波器的 **BNC 外壳通常与保护地相连**。

示波器通道的两个端子作用如下：

- **BNC 中心端**：信号输入端。
- **BNC 外壳**：信号地，通常与示波器机壳、保护地以及其他通道外壳相连，等效电阻接近 `0 Ω`。

因此，虽然 CH3 的中心端可以设置为 `1 MΩ` 输入，但 BNC 外壳仍然不能接到任意“浮动”节点。

## 推荐接法：低端采样

将采样电阻放在回路低端，并让电阻低端与 DG4000 的 BNC 外壳共地：

```text
DG4000 中心端 ── 磁场线圈 ──●── 采样电阻 ── DG4000 BNC 外壳
                            │
                       CH3 BNC 中心端

CH3 BNC 外壳 ─────────────────── DG4000 BNC 外壳
```

此时 CH3 测量的是：

```text
V(CH3 中心端) - V(CH3 外壳)
```

也就是采样电阻两端的电压。线圈和采样电阻仍保持串联，CH3 的 `1 MΩ` 输入只是在采样电阻两端并联一个很大的电阻，通常影响很小。

### CH3 建议设置

- 输入阻抗：`1 MΩ`
- 耦合方式：`DC`
- 探头倍率：按实际探头设置，常用 `1×`
- 在确认回路安全后，再逐步打开 DG4000 输出

## 错误接法：把 CH3 外壳接到线圈高端

下面的接法看起来像是在“跨接”采样电阻，但会改变原有回路：

```text
DG4000 中心端 ── 采样电阻 ──●── 磁场线圈 ── DG4000 BNC 外壳
                            │
                       CH3 BNC 外壳

CH3 BNC 中心端 ─────────────── DG4000 中心端
```

由于 CH3 外壳接地，中间节点被强制接到 DG4000 外壳；而线圈的另一端本来就接 DG4000 外壳，所以线圈两端近似被短接：

```text
线圈两端 ≈ 0 V
```

这时 CH3 虽然可能显示出一个“电阻电压”，但它是在**线圈被旁路、DG4000 负载被改变**的状态下测得的，不能代表正常线圈工作时的电压或电流。因此磁场大小和锁相放大器的 `R` 信号可能明显变化。

如果 CH3 还设置为 `50 Ω`，CH3 中心端接到 DG4000 中心端会进一步给信号源增加低阻负载，影响会更严重。

## 需要测量高端电阻时

如果采样电阻必须放在靠近 DG4000 中心端的高端位置，不能用普通单端 BNC 通道直接跨接电阻。应使用以下方案之一：

1. 使用隔离差分探头；
2. 使用输入和输出均满足额定范围的差分放大器；
3. 重新布置回路，将采样电阻移到低端，再用普通示波器测量。

普通示波器的两个通道也不能简单地用“CH1 正端减 CH2 正端”来代替差分探头，因为两个通道的 BNC 外壳仍然共地，错误接线同样可能造成短路。

## 上电前检查

1. 关闭 DG4000 输出后再插拔 BNC，避免产生瞬态电压和磁场。
2. 确认 CH3 外壳只接 DG4000 的信号地/外壳节点。
3. 确认 CH3 输入阻抗为 `1 MΩ`，除非明确需要 `50 Ω` 端接。
4. 用万用表测量 DG4000 BNC 外壳与示波器 CH3 BNC 外壳之间的电阻，通常应接近 `0 Ω`，以确认公共接地路径。
5. 首次上电时将 DG4000 幅值设为较小值，先观察采样电阻两端电压，再逐步增加输出。
6. 不要为了实现“浮地测量”而拆除示波器或 DG4000 的保护地。
