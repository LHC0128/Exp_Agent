# GS200 直流电压/电流源控制模块

## 概述

`gs200` 是 Yokogawa GS200 直流电压/电流源的 Python 控制模块，通过 PyVISA 使用标准 SCPI 命令与设备通信。

## 依赖

- `pyvisa`：VISA 抽象层

安装：`pip install pyvisa`

## 支持的接口

| 接口 | VISA 资源示例 |
|------|--------------|
| USB (USB-TMC) | `USB0::0x0B21::0x0039::XXXXXXXX::INSTR` |
| Ethernet (VXI-11) | `TCPIP0::192.168.1.10::inst0::INSTR` |
| Ethernet (命令 Socket) | `TCPIP0::192.168.1.10::7655::SOCKET` |
| GP-IB | `GPIB0::1::INSTR` |
| RS-232 | `ASRL3::INSTR` (COM3) |

GS200 的 HTTP 网页、VXI-11 和 7655 命令 Socket 是独立服务，网页可访问不能证明
VISA 命令连接成功。当前网络设备 `9026D6597` 的命令端口
`TCPIP0::192.168.124.41::7655::SOCKET` 已完成身份及状态回读，配置见
[设备库](../../params/devices.yaml)。具体端口见[官方操作手册第 11 章](https://cdn.tmi.yokogawa.com/1/6218/files/IMGS210-01EN.pdf#page=123)。

驱动在 Socket 连接时设置 LF 收发终止符，仪器的发送终止符应配置为 LF 或 CR+LF；
USB、VXI-11、GP-IB 的 VISA 默认终止符保持原值。打开资源或身份查询失败时释放
当前会话并保留原异常，不自动切换通信协议，也不关闭整个共享 VISA 后端。

## 快速开始

```python
from gs200 import GS200Instrument

# 连接设备
gs = GS200Instrument("TCPIP0::192.168.1.10::inst0::INSTR")
gs.connect()

# 输出 100 mA
gs.set_current(0.1)
gs.set_output(True)   # 打开输出

# 关闭输出
gs.set_output(False)

# 断开连接
gs.disconnect()
```

也支持上下文管理器用法：

```python
with GS200Instrument("USB0::0x0B21::0x0039::XXXXXXXX::INSTR") as gs:
    gs.set_current(0.05)
    gs.set_output(True)
```

## API 参考

### 连接管理

| 方法 | 说明 |
|------|------|
| `connect()` | 建立 VISA 连接 |
| `disconnect()` | 断开连接 |
| `connected` (属性) | 返回是否已连接 |
| `idn()` | 查询设备标识 |
| `reset()` | 仪器复位 |
| `clear_status()` | 清除状态寄存器 |

### 输出控制

| 方法 | 说明 |
|------|------|
| `set_output(state)` | 设置输出状态 (True=ON, False=OFF) |
| `get_output()` | 查询输出状态 |

### 电流模式

| 方法 | 说明 |
|------|------|
| `set_current(current)` | 设置电流值 (A)，自动切换源功能并选择量程 |
| `get_current()` | 查询当前电流设定值 |
| `set_current_range(current)` | 设置电流量程 |
| `get_current_range()` | 查询当前量程 |

### 电压模式

| 方法 | 说明 |
|------|------|
| `set_voltage(voltage)` | 设置电压值 (V)，自动切换源功能并选择量程 |
| `get_voltage()` | 查询当前电压设定值 |

### 保护

| 方法 | 说明 |
|------|------|
| `set_voltage_limit(voltage)` | 设置限压值 (V) |
| `get_voltage_limit()` | 查询限压值 |
| `set_current_limit(current)` | 设置限流值 (A) |
| `get_current_limit()` | 查询限流值 |

## GUI 主磁场控制

本地 GUI 的“仪器控制”页面会从 `params/mapping.yaml` 发现
`main_magnetic_field` 对应的 GS200，并使用 `params/safety_limits.yaml` 中的
`-10～10 mA` 安全范围。

GUI 只允许修改电流设定值和输出开关；源模式、电流量程、限压与限流均为只读回读值。
界面中的电流单位为 mA，写入驱动前统一换算为 A。设备处于电压模式时不会把电压电平
误显示为电流；提交新电流会由 `set_current()` 切换到电流模式。

从输出 OFF 切换到 ON 时需要确认目标电流，后端也要求请求携带确认标志，并按“先设置和
校验电流、后开启输出”的顺序执行。设备连接后的写入或回读异常会依据
`output_off_on_error: true` 尽力关闭输出；若关断命令也失败，错误响应会同时报告两个故障。
