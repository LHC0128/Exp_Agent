## 2. 扫描模式

> Skill 根据此字段选择代码模板，生成对应的采集 Cell。

- **`point_by_point`**（逐点扫描）：适合透射谱、磁光 Kerr、XY 校准等。逐点设置→稳定→读数
- **`continuous_ramp`**（连续扫场）：适合灵敏度测量。DG4000 RAMP 波形 + HF2 DAQ 触发同步采集
- **`nested_scan`**（嵌套扫描）：适合 Z 场标定等。外层扫描变量逐点改变，内层在每点做一次完整扫描

## 4. 数据采集与时序

### 每个扫描点记录的数据

| 记录内容 | 对应 mapping key | 说明 |
|---------|-----------------|------|
| 锁相幅度 R | `lockin_r` | demod_idx=0 的 R 值 |
| 锁相 X/Y | `lockin_xy` | demod_idx=1 的 X, Y 值 |
| 示波器波形 | `scope_waveform` | 可选，每点采一帧 |

### 实验时序

| 参数 | 值 | 单位 | 说明 |
|------|----|------|------|
| 扫描前等待 | 5 | s | 温度/磁场稳定后再开始 |
| 每点设置后等待 | 0.5 | s | 设置扫描值后等待响应稳定 |
| 点间间隔 | 0.1 | s | 相邻点间的额外延迟 |
