# GUI 架构图归档

2026-10-14 撤下 GUI 总览页的实验系统架构区域，以及各实验的“架构”Tab 和静态子图。
运行页的可执行交互流程图、可编辑 Excalidraw 原图下载、历史查询与离线分析继续使用。

本目录整体接收原 `GUI/frontend/public/architecture/` 的 122 个文件，包括 32 份正式
HTML/JSON 和 90 份本地验收截图、回执及中间产物。原文件内容保持不变；新增本说明。
正式 HTML/JSON 保留版本管理，验收附件沿用本地忽略规则。

归档 HTML 可在本地浏览器打开，JSON 作为历史图规格保留。图中实验说明、源码路径、
输出路径、版本标记和验收回执中的绝对路径均属于撤下时的历史记录，不作为当前实验入口。
本次不重绘、重生成或校正历史图。图是否能准确表达后续实验实现，需重新核对源码。

本目录位于前端 `public/` 之外，不再由 Vite 或后端的前端构建目录发布。
旧 `/architecture/` 地址不再提供架构图，当前实验说明中的原图链接统一指向本归档目录。
