# θ 走线的适用条件

## 回答的问题

同一工作点上的相位噪声可以用 θ = atan2(y−y0, x−x0) 折算，也可以用 y/K（K = R|cos φ|）折算。
两者在什么条件下等价、什么时候 θ 不能用？

## 脚本

`theta_condition.py` 读一轮运行目录的相图与噪声帧，给出：

- 帧内相角散布（隔离前后）与 θ/y 比值；
- `figures/theta_condition.png|pdf` 四联图：(a) 原始 XY 轨迹、(b) 保留直流低通后的轨迹、
  (c) θ 隔离前后的相位谱与 y 走线、(d) 比值谱。

## 结果

| 条件 | θ 帧内散布 | θ/y（3-50 Hz 中位） | θ 结论 |
| --- | --- | --- | --- |
| 窄带静态档 TC 1 ms（旧链三档） | — | 0.998-1.001 | 可用 |
| 宽带档 TC 1 µs，未隔离 | 1.8135 rad | 0.0022 | 不可用（整周缠绕伪迹） |
| 宽带档 TC 1 µs，保留直流 ≤1.2 kHz 低通 | 0.0168 rad | 1.0012 | 可用，与 y 走线一致 |

物理原因：宽带解调把输入直流偏置混频成 −5 kHz 镜像（A05 拟合里已作为已知干扰项建模），
其幅值 0.68 V 远大于圆半径 13.9 mV；atan2 对该旋转敏感，Σ(非线性)，缠绕后低频信息丢失。
y/K 与切向投影是线性折算，带内估计不受影响，所以测量口径取 y 走线。

## 用处

- 正式分析（`analysis_steps.analyze_data`）据此把 θ 降为诊断项：宽带档先隔离再判可用性
  （散布 ≤ 0.25 rad），并写进 summary 的 `theta_diagnostic` 字段；
- 实验文档与工作总结的「θ 适用条件」小节直接引用本记录与图。
