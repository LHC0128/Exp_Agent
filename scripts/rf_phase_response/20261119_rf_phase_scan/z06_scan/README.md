## 结论

- **宽度**：8.03 µs 仍是唯一同时满足 `|c0|` 最小（5.96 mV）与斜率最大（1.936 mV/deg）的点；4/12 µs 的 `|c0|` 升到 83/32 mV，斜率降到 0.99/0.89。
- **拖尾**：在 −0.06 mA 上，拖尾的作用与零场时相反——它主要压低 `c0`（tail off 10.0 → s_f=0.74 时 3.0 mV），而 `|c±1|` 和斜率基本不变（1.66→1.84）。s_f=0.74 给出本批最低 `c0`。
- **τe**：56.9 µs 使 `c0` 从 5.96 降到 3.95 mV，斜率几乎不变（1.936→1.898）。
- **沿宽**：0.5 µs 使 `c0` 从 5.96 升到 8.18 mV，1.5 µs 升到 20.0 mV；斜率略降（1.888/1.865）。窄沿更有利。
- **单参数结论**：`c0` 可以在保持斜率 ≈1.9 mV/deg 的同时压到 3–4 mV（s_f=0.74 或 τe=56.9）；把两者叠加能否进一步降低，尚未测。

## 注意

- 共振点对主磁场敏感：−0.06 mA 处的斜率约 1.9 mV/deg，是零场的 7 倍；场漂移会直接改变工作点，实际使用需要闭环或回读。
- `N_REPEAT=1`，无逐点误差；TEC（COM13）缺失。
