w10 的 `|c0|≈10.9 mV` 复现（10.91 → 10.88），确认不是瞬时异常；w6/w10 的其他分量在 4–8% 内。

## 场扫描结果

- **X 偏置**：`|c0|` 随 X 从 −50 到 +50 mV 单调上升（12.4 → 15.5 mV），`|c+1|`、`|c−1|` 基本不变，最佳相位稳定在 97–98°。
- **Y 偏置**：`|c0|` 随 Y 从 −50 到 +50 mV 单调下降（18.6 → 4.2 mV），`|c+1|`、`|c−1|` 基本不变，最佳相位稳定在 97–98°。
- **Z 主磁场**：在 −0.1 mA 出现强共振：`|c0|` 65 mV、`|c+1|` 16.7 mV、`|c−1|` 15.7 mV；±0.2 mA 时响应明显变小；最佳相位 90–114°。每次非零主磁场运行在 A04 都恢复运行前状态。
