# 射频相位响应：最大斜率与 c0 归零的扫描方案

目标：在 Z 主磁场、脉宽 $w$、拖尾 $s_f$、拖尾时间 $\tau_e$ 四个参数上找到切线斜率 $|c_{+1}|+|c_{-1}|$ 的最大点，再用 X/Y 偏置把 $c_0$ 归零。X/Y 只平移 $c_0$，不进入斜率搜索。

依据：2026-11-19 的 14 个脉冲参数条件、5 点 Z 粗扫、21 点 Z 细扫（0.02 mA）、25 点 $s_f\times\tau_e$ 网格与正在进行的 25 点局部网格。现有最好点为 $s_f=0.65$、$\tau_e=45$ µs、$w=8.03$ µs、Z=−0.06 mA，斜率 2.078 mV/deg、$|c_0|=3.47$ mV。Z 的峰宽约 0.04 mA，此前 0.02 mA 的步长把峰顶夹在两点之间；GS200 可以设到 µA 级，方案把 Z 步长缩到 0.002 mA。

## 一、固定条件

| 项 | 值 |
| --- | --- |
| 射频 | 5 kHz、50 mVpp、相位 0/360/10°，36 点 |
| 脉冲 | 峰值 190 mA；除扫描参数外 $w=8.03$ µs、沿宽 1.0 µs |
| 拖尾 | 默认 $s_f=0.65$、$\tau_e=45$ µs；精确补偿由这两个参数推导 |
| 主磁场 | 默认 Z=−0.06 mA；Z 扫描时逐点设定 |
| 偏置 | X=−40.9 mV、Y=−6.9 mV；X/Y 归零阶段除外 |
| 采集 | 单点 0.2 s、稳定 0.1 s、温控分组 2、`N_REPEAT=1`（候选点用 3） |
| 数据根 | `<数据根>/rf_phase_response/` |

每个运行仍走 A01 预检、A02 配置、A03 采集、A04 安全收尾；主磁场非零时由 A04 恢复原状态。所有运行必须核验 `raw/phase_response.csv` 为 36 行，行数不足按失败处理。

## 二、阶段与点数

### 阶段 0：噪声基线（3 次，约 7 分钟）

在当前最优点重复 3 次：`N_REPEAT=3`，其余固定。用途：给出斜率与 $c_0$ 的标准差 σ；后续小于 2σ 的差异不追。

### 阶段 1：Z 细扫（21 次，约 46 分钟）

固定 $w=8.03$、$s_f=0.65$、$\tau_e=45$。

- 范围 −0.090…−0.050 mA，步长 **0.002 mA**（−0.090、−0.088、…、−0.050），共 21 点；
- 标签 `z2_m090` … `z2_m050`；
- 每点记录斜率、$|c_0|$、$|c_{\pm1}|$、最佳相位。

分析：对斜率−Z 曲线做洛伦兹或二次拟合，给出峰位 $Z^*$ 与半高宽；对 $|c_0|$−Z 曲线单独拟合，记录其极小位置。若 $Z^*$ 落在扫描边界，向该方向再扩 0.004 mA。

### 阶段 2：峰位验证（3 次，约 7 分钟）

在 $Z^*$ 与 $Z^*\pm0.002$ mA 各测一次，确认峰位不随采样漂移。

### 阶段 3：脉宽一维（8 次，约 18 分钟）

固定 $Z^*$、$s_f=0.65$、$\tau_e=45$。

- $w$ = 4、5、6、7、8.03、9、10、12 µs；
- 标签 `w2_4` … `w2_12`；
- 二次拟合取顶点，得到 $w^*$；若顶点落在 8.03 与 9 之间，补 8.5 µs。

### 阶段 4：沿峰脊的一维扫描（不拟合二次面）

以 (0.65, 45) 为中心的局部网格显示峰在内部，但二次响应面拟合失败：Hessian 有一个特征值接近 0，驻点 (0.584, 38.7) 的预测值 1.967 mV/deg 低于实测 2.078，峰比二次面更尖。因此不再用二维二次面外推，改为沿峰脊扫一维：

- 固定 Z*，沿从 (0.55, 35) 到 (0.70, 45) 的直线取 7 点（$s_f$ 0.55→0.70、$\tau_e$ 35→45，同步步进），标签 `ridge_1`…`ridge_7`；
- 若端点仍升高，向 $s_f$<0.55 或 $\tau_e$<35 再延伸 2–3 点；
- 每个候选点必须满足 `|c0|` ≤ 7 mV（X/Y 偏置的归零能力上限），否则剔除。

找到峰脊上的最大点后，在其法向 ±0.025/±2.5 µs 各补 2 点确认。

### 阶段 5：新参数下重定位 Z（5 次，约 11 分钟）

用 $(w^*,s_f^*,\tau_e^*)$ 重扫 $Z^*$ 附近 ±0.004 mA、步长 0.002（5 点），确认峰位移动量；若移动超过 0.004 mA，以新峰位为准再做阶段 2。

### 阶段 6：X/Y 归零 $c_0$（4 次，约 9 分钟）

$c_0$ 是复数；X/Y 对它的影响近似线性。先在当前点做两个小偏置（X±10 mV、Y±10 mV）测 4 个 $c_0$ 值，得到 2×2 复矩阵 $M$，解

$$\Delta c_0 + M\,[\Delta X,\Delta Y]^T = 0$$

得到偏置增量；设定后测 1 次验证。若残差 > 0.5 mV，再用新斜率修正一次。归零后斜率应不变（历史数据：X/Y 只改 $c_0$）。

### 阶段 7：一轮坐标校验（约 10 次）

以 $(Z^*,w^*,s_f^*,\tau_e^*)$ 为中心，对四个参数各做 ±1 步的单点扰动（0.002 mA、0.5 µs、0.025、2.5 µs），确认没有更优点；若有，沿该方向走一步。最后在候选点做 `N_REPEAT=3`。

总预算：约 70 次运行，约 2.5 小时；可分两次执行（阶段 0–3 一次，阶段 4–7 一次）。阶段 4 的候选点若 `|c0|`>7 mV 直接剔除，不进入后续。

## 三、判定与停止

- 斜率增益 < 2σ 时停止；σ 由阶段 0 给出。
- 峰位拟合的置信区间用残差 bootstrap；若 $Z^*$ 的不确定度大于 0.002 mA，先加密到 0.001 mA 再定。
- $c_0$ 归零后要求 $|c_0|<0.5$ mV 且斜率变化 <2%；否则检查是否扫过共振导致 $c_0$ 跳变。
- 任何阶段出现 A03 超时或空数据，立即停止并检查 MFLI；失败目录保留，不覆盖。

## 四、执行顺序与产物

1. 阶段 0 → 1 → 2 → 3，产物写入 `_rf_phase_scan_20261119/z_fine2/`（图与 CSV）；
2. 阶段 4 → 5 → 6 → 7，产物写入 `_rf_phase_scan_20261119/opt_round1/`；
3. 每阶段结束更新本目录 README 与 `工作总结/2026-12-02/补充材料.md`；
4. 最终候选点给出完整运行目录、参数、斜率、$c_0$、最佳相位与重复性。

## 五、待确认

- 阶段 1 的范围是否取 −0.090…−0.050 mA；若上一轮局部网格显示峰位更靠近 −0.05，可整体右移。
- 阶段 3 是否保留 4 µs 与 12 µs 两个端点（它们远离峰，但对二次拟合有约束）。
- 阶段 6 的 X/Y 小偏置取 ±10 mV 是否足够（历史斜率约 +31.5 / −143.4 mV/V，10 mV 约给 0.3 / 1.4 mV 的 $c_0$ 变化）。
