# 2f 偶部判据离线验证（π 脉冲模式下补平 Bx、By）

## 一句话结论

**可以用**：在当前残余 Bz（≈1426 Hz）和 6.6 µs 脉宽下，10 kHz 复振幅 c2 对 (Bx, By) 两个方向都线性、可解，理想条件下零点严格在 B⊥=0，且不随 Bz、慢拖尾比例和脉宽偏离 π 而移动。**主要误差来自慢拖尾自带的横向分量 `slow_tilt`**（每 0.02 约移 13 nT，随 Bz 减小而变大），其次是线圈轴倾斜 `tilt`（每 0.02 约 4.4 nT）。这两项对 5 kHz 判据同样存在，`slow_tilt` 下 5 kHz 偏得更多（约 57 nT）。

## 方法

- 模型：`harmmodel.py`，从 `../06_model/fitmodel.py` 只读导入 `grid/zwave/cross`，复制 `fundamental()` 的物理部分，改为输出整段 P_x(t) 和任意 n·ω 的复振幅 c_n=(2/T)∫P_x e^{−inωt}dt。射频关闭。原文件未改。
- 基准参数：`../06_model/fits/rf_slow.json`（Γ/2π=548 Hz，w0/2π=1426 Hz，s_f=0.544，τe=46.9 µs），190 mA，升余弦沿 1 µs，脉宽 6.6 µs。γ=7 Hz/nT。
- 验证脚本：`verify.py`；输出 `outputs/verify_log.txt`、`outputs/summary.json`；图 `figures/*.png`。
- 零点用 Newton 法从 (30, −20) nT 出发求 c_n(bx,by)=0（Re、Im 两个实方程，两个实未知数）。
- **信号单位**：拟合复增益 C 是由射频通道定的（射频比例 r 顶到上界），对静态场响应的绝对 mV 没有约束（模型 c0≈1e−5 mV，实测约 15 mV）。所以斜率用相对单位 u：1 u = 基准条件下 5 kHz 对 Bx 的斜率 × 1 nT。

## 已验证（模型内）

### 1. 理想条件下零点位置

pump 沿 z、无 tilt/slow_tilt 时，对 w0 ∈ {700, 1426, 3000} Hz、s_f ∈ {0.544, 1}、脉宽 ∈ {5.0, 6.6, 8.0} µs，c2 的零点都在 B⊥=0（数值 <1e−20 nT）。这是对称性的结果：B 只沿 z 且泵浦沿 z 时 M 始终沿 z，P_x≡0。c1 也同样精确为零（作对照）。

两种例外：
- **w0=0**：c2、c1 对 B⊥ 的 2×2 雅可比秩 1，只有一个方向可测，另一个方向的零点不确定。当前 Bz≠0，不影响。
- **w0=1426 Hz、s_f=0.544、脉宽 8.0 µs**：c2 的雅可比条件数约 4600，一个方向几乎测不到（见第 3 节"斜率随脉宽"），零点数值上漂到 (−25, −10) nT。工作脉宽 6.6 µs 处条件数 3.9，没有这个问题。

### 2. 不理想因素引起的零点移动（基准 w0=1426 Hz、s_f=0.544、6.6 µs）

| 因素 | ε | 10 kHz 零点 (nT) | \|Δ\| (nT) | 5 kHz 零点 (nT) | \|Δ\| (nT) |
| --- | --- | --- | --- | --- | --- |
| slow_tilt x | 0.02 | (+13.0, +1.7) | 13.1 | (+11.0, −56.2) | 57.3 |
| slow_tilt x | 0.05 | (+32.5, +4.1) | 32.8 | (+28.8, −145.4) | 148.2 |
| slow_tilt y | 0.02 | (+16.4, +7.3) | 18.0 | (−1.1, +20.4) | 20.4 |
| slow_tilt y | 0.05 | (+40.9, +18.3) | 44.8 | (−2.9, +51.2) | 51.3 |
| tilt x | 0.02 | (+4.1, −1.6) | 4.4 | 同左 | 4.4 |
| tilt x | 0.05 | (+10.2, −3.9) | 10.9 | 同左 | 10.9 |
| tilt y | 0.02 / 0.05 | — | 4.4 / 10.9 | 同左 | 同左 |
| pump x | 0.02 / 0.05 | (0, +1.6) / (0, +3.9) | 1.6 / 3.9 | 同左 | 同左 |
| pump y | 0.02 / 0.05 | (−1.6, 0) / (−3.9, 0) | 1.6 / 3.9 | 同左 | 同左 |

- 移动量对 ε 线性。
- **pump 倾斜**：零点移动 ≈ ε·Γ/γ（0.02×548 Hz / 7 = 1.57 nT），方向与倾斜方向正交；10 kHz 与 5 kHz 完全相同，与 Bz 基本无关（w0=0 时 1.9 nT）。
- **tilt**：10 kHz 与 5 kHz 零点完全相同；随 Bz 增大（0.02 时 w0=0/700/1426/3000 Hz 对应 3.2/2.5/4.4/8.7 nT）。
- **slow_tilt**：10 kHz 比 5 kHz 稳健（13 对 57 nT），但仍是最大误差项；强烈依赖 Bz（0.02 时 w0=700/1426/3000 Hz 对应 32/13/5.9 nT；w0=0 时无意义）。
- tilt 和 pump 让两个谐波的零点重合，所以**无法靠比较 5 kHz 与 10 kHz 零点把它们识别出来**；slow_tilt 让两者分开，两个零点的差可作为 slow_tilt 存在的指示（见待查）。

### 3. 灵敏度（u/nT；2×2 实雅可比的大/小奇异值，小值决定较难测的方向）

随 Bz（6.6 µs，慢拖尾），图 `figures/sensitivity_vs_bz.png`：

| w0/2π (Hz) | 10 kHz 大/小 | 5 kHz 大/小 |
| --- | --- | --- |
| 0 | 0.77 / 0 | 2.57 / 0 |
| 500 | 1.05 / 0.30 | 1.95 / 0.31 |
| 1000 | 1.27 / 0.31 | 1.40 / 0.36 |
| 1500 | 1.41 / 0.36 | 1.17 / 0.32 |
| 2000 | 1.56 / 0.45 | 1.11 / 0.26 |
| 3000 | 2.06 / 0.77 | 1.23 / 0.10 |

- 当前 Bz≈1426 Hz 处，10 kHz 与 5 kHz 的灵敏度同量级（小奇异值 0.36 对 0.32）；Bz 越大 10 kHz 越占优，Bz→0 时两者都丢失一个方向。
- 随脉宽（w0=1426 Hz），图 `figures/sensitivity_vs_width.png`：10 kHz 的小奇异值在 5–6 µs 最大（约 0.49），6.6 µs 处 0.35，**8.0 µs 处降到 0**；5 kHz 在 **7.0 µs 处降到 0.006**。工作点 6.5–6.7 µs 离两者的盲点都有 1 µs 以上的余量。

### 4. 三点线性求解流程

做法：每轴取 {−d, 0, +d} 三个偏置（另一轴不动），回归复斜率，用中心值和两轴斜率解 2×2 实方程，加上补偿后重复。起点残余 B⊥ 取拟合值（约 91 nT，仅作量级参考）。噪声以 u 计（每个测点独立复高斯，20 次 rms）。

| 条件 | d (nT) | 噪声 (u) | 第 1/2/3 次后误差 (nT) |
| --- | --- | --- | --- |
| 理想 | 5 / 20 / 50 | 0 | 2.9 / 0.00 / 0.00 |
| 理想 | 20 | 0.1 | 2.9 / 0.09 / 0.08 |
| 理想 | 20 | 0.5 | 5.1 / 0.55 / 0.41 |
| 理想 | 5 | 0.5 | 12.2 / 2.1 / 0.55 |
| slow_tilt 0.02 | 50 | 0 | 3.5 / 0.10 / 0.10 |
| pump 0.02 | 20 | 0 | 2.8 / 0.002 / 0.002 |

（误差相对各自的真零点；真零点本身已按第 2 节偏离 B⊥=0。）

- 从约 91 nT 起步，一次求解剩约 3 nT（约 3%），来自 c2 在 Γ/γ≈78 nT 量级上的非线性；**需要第二次迭代**，第二次后受噪声限制。
- 噪声下误差 ≈ 噪声/(小奇异值·d) 量级：d 取 20–50 nT 比 5 nT 稳得多；d=50 nT 时 slow_tilt 下有约 0.1 nT 的非线性残差，可忽略。
- 建议：d≈20–30 nT，迭代 2 次，第 2 次可以缩小 d。

## 待查

1. **实际 slow_tilt、tilt、pump 倾斜的大小**。模型只给出"每 0.02 移动多少"；实测 S 中的拖尾横向分量（报告 §L）说明 slow_tilt 不为零，但拟合中它与静态场简并，数值待定。若 slow_tilt ~0.02，补偿零点会偏 10–20 nT，这比 B⊥ 在 Γ 尺度上的显著性小，但不是 "B⊥=0"。
2. **绝对灵敏度（mV/nT）与 MFLI 在 10 kHz 的实际噪声**。需要 X/Y 偏置线圈的 nT/mV 常数和一次 2f 解调实测；目前只有相对单位。
3. **用 5 kHz 与 10 kHz 两个零点之差估计 slow_tilt** 的可行性：tilt 和 pump 不让两者分开，slow_tilt 让两者分开，原则上可分离；未做数值反演。
4. 模型局限：单时间常数慢拖尾、慢拖尾横向分量与 z 慢分量同形、场均匀。多时间常数或场不均匀会怎样移动零点，未模拟。
5. MFLI 2f 解调的相位约定（谐波 n=2 的参考相位）对"复数零点"无影响，但实施时两个分量 X、Y 都要用，不能只看 R 的极小（R 的极小在噪声下有偏）。
